# FileLynx

Lightweight web file browser, editor, terminal, notebooks, FTP and S3 client for your VPS.

## Requisitos
- Node.js >= 20
- npm o pnpm

## Instalación
```bash
git clone [https://github.com/Ryuzei-Ts/FileLynx.git](https://github.com/Ryuzei-Ts/FileLynx.git)
cd FileLynx
npm install
cp .env.example .env
npm run dev
